# Architecture Decision Records

ADRs record decisions with lasting coupling or recovery consequences. Accepted
records are historical: when a decision changes, add a new ADR and mark the old
record as superseded rather than rewriting its original reasoning.

The proposed [VPN-compatible addressing decision](0020-propose-vpn-compatible-lab-addressing.md)
does not authorize renumbering or supersede the retained ADR 0015 until approved.
